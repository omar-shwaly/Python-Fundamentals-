## 📂 محتويات المستودع (Repository Structure)

### 🛠️ 2. المشاريع والتطبيقات العملية (Mini Projects)
تطبيقات تفاعلية تحاكي أنظمة حقيقية باستخدام البايثون وتدعم التعامل مع القوائم والملفات النصية:
* 🏦 **ATM Simulation:** محاكاة لنظام السحب والإيداع بالصراف الآلي.
* 🔒 **Password Attempts:** نظام التحقق من محاولات كلمة السر.
* 👥 **Practical Membership Control:** إدارة الاشتراكات والصلاحيات.
* 📊 **Student Performance Analyzer & Grades Manager:** تحليل أداء الطلاب وإدارة درجاتهم.
* 📝 **Todo List:** تطبيق إدارة المهام اليومية.
